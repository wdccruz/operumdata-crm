Política de privacidade do CRM OperumData

Última atualização: 16/11/2026.

O CRM OperumData é um sistema interno de uso restrito, acessado apenas por pessoas convidadas pela OperumData. Esta página descreve como o CRM trata os dados da conta Google quando o usuário conecta, por vontade própria, o Google Agenda.

Dados acessados

  • Endereço de e-mail da conta Google conectada, para identificar a conexão.
  • Eventos da agenda escolhida (por padrão, a agenda principal): título, local, data e horário. Esses dados ficam visíveis somente para o próprio usuário dentro do CRM.
  • O CRM cria, altera e remove na agenda do usuário os eventos das reuniões comerciais registradas no CRM.

Uso e compartilhamento

Os dados são usados apenas para sincronizar a agenda do usuário com o CRM. Não são vendidos, usados para publicidade, compartilhados com terceiros nem usados para treinar modelos de inteligência artificial. O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Armazenamento e segurança

O token de autorização e os eventos sincronizados ficam no banco de dados do CRM (Supabase), protegidos por controle de acesso por usuário. O token nunca é enviado ao navegador.

Revogação e exclusão

O usuário pode clicar em "Desconectar" na página Agenda do CRM a qualquer momento. Isso revoga o acesso, apaga do CRM os eventos importados do Google e remove do Google os eventos criados pelo CRM. O acesso também pode ser revogado em myaccount.google.com/permissions.

Contato

Dúvidas sobre privacidade: fale com o administrador do CRM OperumData pelo e-mail de suporte informado na tela de autorização do Google.

CRM OperumData privacy policy (summary)

The CRM is an internal, invitation-only system. When a user chooses to connect Google Calendar, the CRM reads the account email and calendar events (shown only to that user) and creates, updates and deletes events for CRM meetings. Data is used only for this sync, is never sold, used for advertising, shared with third parties or used to train AI models, and follows the Google API Services User Data Policy, including the Limited Use requirements. Users can disconnect at any time on the CRM Agenda page, which revokes access and deletes the imported events.
